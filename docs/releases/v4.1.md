A fix for Stereo Loom not starting on some PCs, Zondision's newest SDK, and much more of what Zondision's displays and glasses can do.

## Bug fixes
- **Fixed Stereo Loom not starting** with "The procedure entry point CreateDirect3D11DeviceFromDXGIDevice could not be located". This happened when another program's `d3d11.dll` or `dxgi.dll` (from geo-11, 3DMigoto or ReShade, for example) was in the same folder as `StereoLoom.exe`, such as Downloads. Stereo Loom now always uses Windows' own copies, and notes any it skipped in the log.
- **Fixed the update notice** missing releases with a third number in their version (such as 4.1.1).

## Zondision
- **Updated to Zondision's 3DS SDK 5.0.4.5**, which fixes clashes with a Leia SR display connected at the same time. Use it with Zondision's latest 3DS software.
- **A Mode list** under the Zondision output, showing what is connected:
    * **Glasses-free (eye tracked)**, as before. A Half Top-and-Bottom source now goes to displays with multiview firmware as it is, with no conversion.
    * **Multiview** and **Multiview (picture + depth)**, for displays with multiview firmware: many views at once, no eye tracking, with a 3D Strength slider. Picture + depth sends an RGB + Depth source straight to the display.
    * **Shutter, Polarised and AR glasses**, for Zondision's glasses (shutter is experimental).
- **No more flicker when 3D switches on or off.** The screen goes black for a moment while the display switches. Hide 3D Switch Flicker turns this off.
- **Uses the display picked in Zondision's control panel** when more than one is connected.
- **Follows the display being unplugged and plugged back in**, and Zondision's service restarting.

## Leia SR
- **Follows the SR display being unplugged and plugged back in**, or its runtime restarting: the 3D starts again by itself.

## Known issues
- Zondision uses Zondision's evaluation app key in this release, which expires on 1 January 2027. A release with Stereo Loom's own key will follow.
